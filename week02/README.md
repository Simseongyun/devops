## 오늘 배운 내용
- 가상화: 베어메탈 / 하이퍼바이저(VM) / 컨테이너의 차이
- WSL2와 Ubuntu로 리눅스 실습 환경 구축
- 리눅스 기본 명령어 (pwd, ls, cd, mkdir, cat, cp, mv, rm, chmod)
- Git 기본 (init, add, commit, log, switch, diff, branch)
- GitHub 가입, gh 로그인, 레포 생성과 push

## 새로 배운 명령어
```bash
wsl -l -v
git add . && git commit -m "메시지"
git log --oneline --all --graph
gh repo create devops --public --source=. --remote=origin --push
```
